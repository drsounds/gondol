# Modules

Every module is imported by its path, `gondol/<path>` for `src/<path>.ts(x)`. The list in
`package.json` `exports` is generated by `bun run exports`. Stylesheets, the design system's files
and assets are exported as they are: `gondol/styles/*`, `gondol/design-system/*`, `gondol/assets/*`.

## `gondol`

| Export | |
| --- | --- |
| `configureGondol`, `GondolConfig` | Registers an app with gondol. See [Configuration](./configuration.md). |
| `Register`, `EntityType`, `MessageKey` | Type augmentation. |
