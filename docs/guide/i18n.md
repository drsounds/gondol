# Internationalization

Gondol's own strings (the shell, entity sheets and menus, search, the global filter and the theme
settings) ship in English and Swedish. Your app adds its own catalogue, merged over gondol's, and
can reword any of gondol's strings by using the same key.

## The catalogue

Catalogues are flat objects per locale. Placeholders use `{name}`; `en` is the fallback for any key
missing in another locale.

```tsx
// src/lib/i18n.tsx
import type { ReactNode } from "react";
import { I18nProvider as GondolI18nProvider, useI18n as useGondolI18n } from "gondol/i18n/i18n";
import type { GondolMessageKey } from "gondol/i18n/messages";

const MESSAGES = {
  en: {
    "app.name": "My App",
    "nav.notes": "Notes",
    "notes.new": "New note",
    "notes.count": "{count} notes",
    "entity.note": "Note",
    "entity.notebook": "Notebook",
  },
  sv: {
    "app.name": "Min app",
    "nav.notes": "Anteckningar",
    "notes.new": "Ny anteckning",
    "notes.count": "{count} anteckningar",
    "entity.note": "Anteckning",
    "entity.notebook": "Anteckningsbok",
  },
} as const;

export type MessageKey = keyof (typeof MESSAGES)["en"] | GondolMessageKey;

export function I18nProvider({ children }: { children: ReactNode }) {
  return <GondolI18nProvider messages={MESSAGES}>{children}</GondolI18nProvider>;
}

export const useI18n = useGondolI18n;
```

Register the key type so every `t()` call, in your code and in gondol's, is checked:

```ts
declare module "gondol" {
  interface Register {
    messageKey: MessageKey;
  }
}
```

## Translating

```tsx
const { t, locale, setLocale, intlLocale } = useI18n();

t("notes.new");                       // "New note"
t("notes.count", { count: 3 });       // "3 notes"
new Intl.DateTimeFormat(intlLocale).format(date);
setLocale("sv");
```

`intlLocale` is the BCP 47 tag for dates and numbers (`en-US`, `sv-SE`). A key with no string in
any locale renders as the key itself.

## `I18nProvider` options

| Prop | Meaning |
| --- | --- |
| `messages` | Your catalogue, merged over gondol's (`GONDOL_MESSAGES`). |
| `locales` | The locales a user can pick; defaults to your catalogue's. |
| `intlLocales` | BCP 47 tags per locale; defaults to `DEFAULT_INTL_LOCALES` (`en-US`, `sv-SE`). |
| `storageKey` | Where the user's pick is stored in `localStorage`. |

The provider starts on `en` so server and client markup match, then adopts the stored choice or the
best match from the browser's languages, and sets `<html lang>`.

## Keys gondol reads from your catalogue

- `entity.<type>` for every entity type: the type's name in search results, filter chips, type
  labels and pickers.
- `app.name`, which gondol defaults to "Gondol".
- Labels you pass as message keys, such as `SearchBrowseTile.label`.

## Adding a locale

Add the locale to your catalogue and to `intlLocales`. Gondol's own strings then fall back to
English in that locale until they are translated in `src/i18n/messages.ts`.
